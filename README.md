# 📊 Bajaj Executive Sales Intelligence Dashboard

A fully interactive, single-file HTML dashboard built for the **CEO and CFO of Bajaj**, providing deep insights into 4 years of US retail sales data (2018–2021).

##  Live Demo
👉 [Click here to view the Dashboard](https://faisaln1009.github.io/bajaj-dashboard/Bajaj_Executive_Dashboard.html)

##  Features
- 5 KPI Cards (Revenue, Profit, Orders, Discount, Customers)
- 11 Interactive Charts
- 6 Filters (Year, Region, Segment, Category, Ship Mode, Discount)
- Auto-updating Insights Panel

##  Tech Stack
- HTML5, CSS3, JavaScript
- Chart.js v4.4.1
